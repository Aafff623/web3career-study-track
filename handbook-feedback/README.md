# Handbook Feedback

> 学习过程中对 Handbook 的反馈、问题和建议。

## 用途

记录在阅读 Handbook 过程中发现的问题：

- 错别字 / 排版问题
- 概念表述不清楚
- 资料链接过期
- 结构组织建议
- 缺失的知识节点

## 每条 Feedback 格式

| 字段 | 说明 |
|------|------|
| Handbook 页面 | 对应的 Handbook 链接 |
| 问题描述 | 具体是什么问题 |
| 建议改法 | 你觉得怎么改更好 |
| 来源 | 在哪个学习阶段发现的（如：预习 AI 基础 / Week 1 课程） |

## 提交流程

1. 在本目录下创建 Markdown 文件，命名格式：`YYYY-MM-DD-简短描述.md`
2. 按上述格式填写内容
3. commit & push
4. 如需向 Handbook 官方提交，参考 [参与共建](https://aiweb3.school/zh/contribution/) 或 [GitHub](https://github.com/lxdao-official/aiweb3school)
