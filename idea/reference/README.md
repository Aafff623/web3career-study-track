# reference ｜ 参考资料

存放 skill 迭代过程中需要的模拟场景、经典案例和评估规范。

## 目录结构

```
reference/
├── README.md
├── case/       # 实际测试中的经典案例（输入→输出对照）
└── eval/       # 进化规范：评估标准、断言模板、评分规则
```

## case/

存放 skill 测试中收集的经典案例，用于：
- 回归测试：确保改进不破坏已有能力
- 质量基准：衡量批注质量、格式一致性
- 新手参考：展示"好的输出"长什么样

每个案例包含：
- 输入（Handbook 原文 / 日志原始数据）
- 期望输出（标准答案或参考输出）
- 评分维度

## eval/

存放 skill 进化过程中的规范文件：
- 评估标准（哪些维度要打分）
- 断言模板（程序化验证规则）
- 评分规则（定性评判的依据）
- 迭代记录（每轮改进了什么、为什么）
