# 实践：最小合约阅读练习

> 模块：Web3 基础 · 智能合约

## 目标

通过阅读一个已验证源码的真实合约，建立"读合约"的基本能力：找到状态变量、写操作、权限函数和事件，理解合约的风险边界。

## 流程

1. 找一个已验证源码的简单 ERC-20 或 NFT 合约。
2. 在区块浏览器里查看源码、ABI、事件和最近交易。
3. 找出哪些函数会改变状态，哪些只是读取状态。
4. 找出合约的权限函数，例如 owner、admin、pause、mint、burn、upgrade。
5. 找出最重要的 event，并解释它对应哪类用户动作。
6. 用一句话解释：这个合约最重要的风险边界是什么。

## 验收标准

- [ ] 能在区块浏览器上定位已验证合约的源码和 ABI
- [ ] 能区分 read-only 函数和写操作函数
- [ ] 能识别合约的权限函数（owner/pause/mint 等）
- [ ] 能指出最重要的 event 及其对应的业务动作
- [ ] 能用一句话描述合约的核心风险边界
