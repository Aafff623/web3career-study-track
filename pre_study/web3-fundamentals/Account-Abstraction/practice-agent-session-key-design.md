# 实践：Agent Session Key 策略设计

> 模块：Web3 基础 · Account Abstraction

## 目标

为一个具体 Agent 场景设计 Session Key 权限策略，理解如何把"全部允许"拆成可验证的规则集。

## 流程

1. **选定场景**——例如"每小时最多再平衡一次测试网小额资产"
2. **定义合约与方法**——写清楚允许调用的合约地址和具体方法签名
3. **设定约束维度**：
   - 额度上限（单次/累计）
   - 过期时间
   - 链 ID
   - 最大交易次数
4. **划分确认边界**——哪些动作必须回到用户钱包手动确认
5. **设计撤销机制**——如何撤销 session key，以及如何审计它的执行历史

## 验收标准

- [ ] 选定一个具体的 Agent 场景（不能是泛化的"自动交易"）
- [ ] 清晰列出允许的合约地址和方法
- [ ] Session Key 策略包含时间、额度、链 ID、次数四个约束维度
- [ ] 明确划分了"Agent 可自动执行"和"必须用户确认"的动作
- [ ] 描述了撤销和审计机制
