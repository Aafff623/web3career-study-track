# 实践：DeFi 交易拆解

## 目标

通过拆解一笔真实的 swap 交易，理解 DeFi 交易在链上的执行过程，识别滑点、路由、手续费和价格影响的来源，为后续设计 AI Agent 的 DeFi 交易限制建立基础认知。

## 流程

1. 从 Etherscan 或其他区块浏览器上找一笔近期的公开 swap 交易（如 Uniswap V3 的 ETH/USDC 交易），复制交易哈希。
2. 在区块浏览器中打开这笔交易，查看 Input Token、Output Token、交易路由路径和执行结果。
3. 记录交易的预期输出数量和实际输出数量，计算实际滑点。
4. 找到交易经过的池子或路由合约，查看池子的流动性深度。
5. 分析手续费结构：交易本身收了多少 gas，协议层收了多少 swap fee，是否被 MEV 搜索者抽走额外利润。
6. 总结：如果让 AI Agent 自动执行同类 swap，需要设定哪些安全限制（额度上限、滑点容忍度、路由白名单、模拟检查、人工审批阈值）。

## 验收标准

- [ ] 能正确识别一笔 swap 交易的输入 token、输出 token 和路由路径
- [ ] 能计算实际滑点并解释滑点产生的原因
- [ ] 能找到交易涉及的流动性池并评估其深度
- [ ] 能列出 AI Agent 执行 DeFi 交易时必须具备的安全限制
