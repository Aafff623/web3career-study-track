# 实践：测试网交易追踪

> 模块：Web3 基础 · Network

## 目标

完成一笔测试网交易的完整追踪流程，理解从签名到浏览器可见的全链路，并思考 AI Agent 在每个环节的角色。

## 流程

1. **领取测试 ETH**——在测试网 faucet 领取少量测试资产
2. **发送交易**——用测试钱包发送一笔转账，或调用一个简单合约
3. **浏览器追踪**——在区块浏览器查看：
   - 交易状态（pending → confirmed）
   - 区块号、gas used
   - from / to 地址
   - logs（如果调用了合约）
4. **记录时间**——从交易发出到 confirmed 用了多久
5. **跨链对比**——切换到另一条网络，观察同一地址的余额和交易历史是否不同
6. **Agent 角色分析**——写下：如果这个流程由 AI Agent 辅助，哪些字段必须由工具读取，哪些描述可以由模型生成

## 验收标准

- [ ] 完成至少一笔测试网交易，并在区块浏览器中找到该交易
- [ ] 能列出交易的关键字段（txHash, blockNumber, gasUsed, status）
- [ ] 记录了 pending → confirmed 的时间
- [ ] 至少在两条不同网络上观察了同一地址的状态差异
- [ ] 写出了 Agent 辅助场景下"工具读取 vs 模型生成"的分工清单
