# 最小实践：推理方案对比

> 来源：Inference 模块 · 练习类型：部署决策评估

## 目标

用同一个任务对比不同推理方案，学会把模型选择放进真实约束里。

## 任务

选择一个固定任务，例如：
- "总结一笔交易的风险"
- "从合约 ABI 中提取可调用方法"

## 对比方案

### 方案 A：托管 API 模型

用 OpenAI / Anthropic 等云端 API 跑一次。

### 方案 B：本地模型或较小模型

用 Ollama / llama.cpp 等本地方案跑一次。
