# 最小实践：只读 MCP Server

> 来源：MCP 模块 · 练习类型：Server 搭建 + 权限设计

## 目标

搭建一个只读 MCP server，体验工具暴露、schema 设计和权限边界的完整链路。

## 工具定义

server 只暴露两个工具：

### search_docs(query)

- 功能：搜索本地项目文档
- 参数：`query`（string，必填）
- 返回：匹配的文档片段列表，每条带来源路径

### get_file(path)

- 功能：读取白名单目录里的文件
- 参数：`path`（string，必填）
- 返回：文件内容 + 来源路径

## 约束

- 不能读取白名单外路径
- 返回结果必须带来源路径
- 工具调用要写日志
- 错误要明确返回，而不是静默失败

## 权限升级方案

完成只读版本后，设计一个"写入工具"的权限升级方案：

1. 什么时候需要用户确认
2. 如何撤销授权
3. 如何审计每次调用
