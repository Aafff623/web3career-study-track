# Protocol Documentation RAG Q&A ｜ 协议文档 RAG 问答

> 关联章节：[RAG](./README.md) · 状态：⚪ 未完成

## 练习目标

测试 RAG 的边界处理能力：能否准确找到文档、能否在找不到时拒答、能否识别版本不确定性。重点是证据链的完整性，不是 UI。

## 任务描述

做一个"协议文档 RAG 问答"的最小版本。

选择一个官方文档站，抓取 10 到 20 篇页面，按标题结构切 chunk，存入向量库。用户提问时，系统返回答案和引用。

## 测试用例

至少测试三类问题：

1. **文档中明确存在的 API 用法** — 验证检索准确性
2. **文档中不存在的问题** — 要求系统拒答
3. **旧版本或不确定版本的问题** — 要求系统提示需要核对版本

## 输出要求

输出时强制区分：

```json
{
  "answer": "",
  "sources": [],
  "uncertainties": [],
  "needs_version_check": false
}
```

## 验收标准

- [ ] 完成文档抓取和 chunking
- [ ] 向量库可检索
- [ ] 测试用例 1：能找到正确文档
- [ ] 测试用例 2：能拒答并说明原因
- [ ] 测试用例 3：能提示版本不确定性
- [ ] 输出包含 sources 和 uncertainties
