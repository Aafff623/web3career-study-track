# Transaction Explainer ｜ 交易解释器

> 关联章节：[LLM](./README.md) · 状态：⚪ 未完成

## 练习目标

把**模型生成、链上事实、来源边界、不确定性**分开。重点不是让解释很漂亮，而是验证你能否在工程上区分这四者。

## 任务描述

做一个"交易解释器"的最小版本。

输入一笔交易哈希，让系统读取交易详情、事件日志和相关合约 ABI，然后让 LLM 生成一段解释。

## 输出要求

解释需包含：

1. 用户发起了什么动作
2. 涉及哪些资产和地址
3. **哪些信息来自链上数据，哪些是模型推断**
4. **模型不确定的地方**
5. 如果要签类似交易，用户应该检查什么

## 验收标准

- [ ] 能从链上读取交易详情和事件日志
- [ ] 能获取相关合约 ABI
- [ ] LLM 输出明确区分"链上事实"和"模型推断"
- [ ] 输出包含不确定性说明
- [ ] 输出包含用户检查建议
