# 挑战：Vibe Coding 工具配置

> 来源：Vibe Coding 模块 · 练习类型：环境搭建

## 目标

在自己的电脑上安装并配置至少一个 Vibe Coding 工具，确认它能在一个测试 repo 中正常使用。

## 可选工具

- Claude Code
- Codex CLI
- OpenCLI

## 完成标准

1. 能启动工具并读取当前项目
2. 已配置必要的模型、API key、浏览器桥接或本地工具权限
3. 能让工具完成一个只读任务，例如：
   - 解释目录结构
   - 搜索相关文件
   - 总结某段代码
4. 能让工具完成一个低风险小改动，例如：
   - 补一段注释
   - 生成一个脚本
   - 修改一处测试
5. 保留验证记录：工具版本、配置方式、执行命令、关键输出或截图
