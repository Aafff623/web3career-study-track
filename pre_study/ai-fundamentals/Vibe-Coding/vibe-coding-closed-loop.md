# 最小实践：Vibe Coding 工程闭环

> 来源：Vibe Coding 模块 · 练习类型：完整工程流程

## 目标

选择一个小功能，让 AI Coding Agent 完成一轮完整工程闭环。重点不是功能本身，而是体验"人设边界 → Agent 执行 → 人审查"的协作模式。

## 流程

1. **写清楚任务边界**
   - 明确要做什么
   - 明确不能改的文件
   - 明确验收标准

2. **让 Agent 搜索相关代码并给出计划**
   - 观察 Agent 的搜索策略
   - 检查它是否理解了项目结构

3. **让 Agent 做最小 patch**
   - 只改必要的文件
   - 不要让 Agent 顺手重构

4. **运行测试或构建**
   - 验证改动没有破坏现有功能

5. **查看 git diff，手动审查结果**
   - 检查修改文件列表
   - 检查是否有不该提交的内容
   - 检查代码风格是否一致

6. **要求 Agent 写 PR summary 和验证说明**

## 复盘

完成后记录：
- 哪些信息给少了导致 Agent 走偏
- 哪些测试缺失导致无法自动验证
- 哪些改动需要人类判断而 Agent 没有停下来
