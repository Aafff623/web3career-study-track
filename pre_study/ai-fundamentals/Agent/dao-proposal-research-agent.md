# DAO Proposal Research Agent ｜ DAO 提案研究 Agent

> 关联章节：[Agent](./README.md) · 状态：⚪ 未完成

## 练习目标

建立"只读→候选写入→人工确认→执行"的渐进式权限模型。先做只读 Agent，再做权限升级版。

## 任务描述

### Phase 1：只读 Agent

做一个"DAO 提案研究 Agent"的最小版本，**只能执行只读动作**：

1. 读取提案正文
2. 检索论坛讨论
3. 总结支持和反对理由
4. 标记缺失信息
5. 输出投票前检查清单

### Phase 2：权限升级版

只有当用户明确授权，并经过投票交易 simulation 后，系统才允许生成投票交易草稿。

## Phase 1 输出要求

Agent 在输出里必须明确：

- 用了哪些来源
- 哪些结论证据不足
- 是否发现治理或资金风险
- 如果用户要投票，还需要人工检查什么

## 验收标准

### Phase 1
- [ ] Agent 只执行只读操作
- [ ] 输出包含来源列表
- [ ] 输出包含不确定性说明
- [ ] 输出包含投票前检查清单

### Phase 2
- [ ] 需要用户明确授权才能生成交易草稿
- [ ] 投票前必须经过 simulation
- [ ] 交易草稿包含完整参数
