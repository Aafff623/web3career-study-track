## 练习目标

通过直接 API vs 框架的对比，理解框架在可读性、可扩展性、可调试性和可测试性上的实际价值。重点不是选冠军，而是看清框架到底帮了你什么。

## 任务描述

同一个任务，用两种方式实现：

1. **直接调用模型 API**：用户问题 + 检索结果 + JSON 输出
2. **使用一个框架**：同样的输入输出，但加入 tool schema、trace、失败重试和测试样本
