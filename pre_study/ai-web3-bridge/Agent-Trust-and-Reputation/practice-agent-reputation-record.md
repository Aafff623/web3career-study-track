# Practice: 设计 Agent 任务声誉记录

> 模块：AI × Web3 交叉 · Agent-Trust-and-Reputation

## 目标

设计一个 Agent 完成任务后的声誉记录系统，覆盖评价、验证、stake 和 slashing。

## 场景

Agent 完成了一份"合约风险摘要"任务，需要记录声誉数据。

## 流程

1. 定义任务记录字段：Agent id、用户 id、任务输入 hash、交付物 hash、付款记录、时间戳
2. 设计 review 字段：准确性（1-5）、及时性（按时 / 延迟）、是否需要返工（Y/N）、具体问题描述
3. 设计 validation 字段：验证者身份、验证方式（脚本 / AI / 人工）、是否可复现、验证时间
4. 设计 stake 相关：Agent 抵押金额、抵押资产、锁定期
5. 设计 slashing 条件：什么情况下罚没（超时 / 伪造 / 矛盾结果）、罚没比例、申诉窗口
6. 设计时间衰减：多久以前的记录权重降低

## 验收标准

- [ ] 任务记录包含输入 hash + 交付 hash + 付款记录
- [ ] review 绑定任务 ID + 评价者身份
- [ ] validation 区分能力验证和结果验证
- [ ] stake 有明确的抵押物 + 锁定期 + 释放条件
- [ ] slashing 有违约证据定义 + 挑战窗口 + 申诉路径
- [ ] 声誉有时间衰减机制
