# 第七课：接下来做什么

![](https://i1.hdslb.com/bfs/archive/6737b980ef62367a2de8dd77070b1ca428fd4bdc.jpg)

### 核心主题
- 本节课主要回答一个问题：学完 Web3 开发基础之后，下一步应该做什么？
- 主讲人给出的方向不是继续停留在理论学习，而是尽快进入真实场景，通过黑客松、开发者社区、行业活动等方式，把 ERC20、NFT、Hardhat、CCIP 跨链等知识转化为可展示的项目经验，并逐步建立行业连接。
- > *批注：这一课更像是"学习闭环"的最后一环。技术课程学完后，最重要的不是再无限刷教程，而是做项目、参与活动、积累作品和人脉。*

---


### 核心路径


#### 1. 参加黑客松：用真实项目练手
- 黑客松是"黑客"和"马拉松"的结合，通常指开发者、设计师、产品经理等角色在限定时间内组队，围绕某个主题快速开发一个项目。
- 在 Web3 领域，黑客松尤其适合刚完成系统学习的开发者，因为它可以同时提供三类价值：

| 价值 | 说明 |
|---|---|
| 实战练习 | 将课程中学到的智能合约、前端交互、跨链、NFT 等知识真正落地 |
| 结识同行 | 与开发者、设计师、产品经理、项目方建立联系 |
| 作品与奖金 | 优秀项目有机会获得奖金，也能成为求职或合作时的作品集 |

- 主讲人重点推荐 Chainlink 线上黑客松。Chainlink 每年通常会举办一到两次线上黑客松，时间大致集中在每年 4 月底和 10 月底。从 2020 年到 2024 年，已经举办过多次。
- 参与方式相对明确：
1. 在线报名；
2. 组队或个人开发项目；
3. 提交项目的 GitHub 仓库；
4. 提交约 5 分钟的项目介绍视频；
5. 等待评委评分与发奖。
- > *批注：对新人来说，黑客松的意义不只是拿奖。哪怕没有获奖，只要项目完整、代码可读、演示清楚，就已经能作为很好的简历材料。*

---


#### 2. 关注更多黑客松平台
- 除了 Chainlink 官方黑客松，主讲人还建议关注其他黑客松平台，获取更多参与机会。

| Chainlink Hackathon | Chainlink 官方线上黑客松，适合 Web3 开发者练习预言机、跨链、智能合约应用 |

- > *批注：这些平台适合长期关注。Web3 行业机会往往不是一次性出现的，而是通过持续参与社区、活动、黑客松逐渐积累出来。*

### 进一步参与行业的方式


#### Chainlink 开发者大使计划
- 如果希望更深入参与 Web3 行业，主讲人提到 Chainlink 正在招募开发者大使。
- 成为开发者大使后，可能获得：
  - Chainlink 官方技术培训；
  - 更多行业资讯；
  - 更深入的社区参与机会；
  - 与开发者、项目方、生态伙伴建立连接的机会。
- 这类角色更适合已经具备一定技术基础，并愿意参与社区建设、技术传播或开发者教育的人。
- > *批注：开发者大使不只是"头衔"，更像是进入生态内部网络的一种方式。对想长期发展的人来说，社区贡献和公开输出会逐渐转化为可信度。*

### 行动建议


#### 短期：完成一个可展示项目
- 学完课程后，建议不要只停留在代码片段，而是尽快完成一个完整项目，例如：
  - ERC20 代币应用；
  - NFT 铸造与展示平台；
  - 使用 Hardhat 的智能合约项目；
  - 集成 Chainlink 服务的 DApp；
  - 基于 CCIP 的跨链示例项目。
- 项目最好包含：
  - GitHub 仓库；
  - README 文档；
  - 部署地址或演示视频；
  - 合约地址；
  - 使用说明；
  - 简要的技术架构说明。


#### 中期：参加一次黑客松
- 选择一个合适的 Web3 黑客松，围绕课程中学到的技术做一个完整作品。重点不只是"炫技"，而是让项目具备清晰的问题、合理的功能、可运行的 Demo 和简洁的展示。


#### 长期：进入开发者社区
- 持续关注 Chainlink、DoraHacks、Devpost 等平台，参与线上分享、线下活动、社区讨论和开发者计划。通过持续输出项目、文章、Demo 或开源贡献，逐渐建立自己的 Web3 开发者身份。

---


### 本课要点总结
- 学完 Web3 开发课程后，下一步最重要的是进入真实实践场景。黑客松是非常适合新手开发者的起点，它能帮助你把智能合约、NFT、Hardhat、跨链等知识整合成完整项目，同时认识同行并积累作品。Chainlink 每年会举办线上黑客松，通常只需在线报名，并提交 GitHub 仓库和项目介绍视频。除此之外，也可以关注 Devpost、DoraHacks 等平台，获取更多竞赛和资助机会。若希望更深入进入行业，可以申请 Chainlink 开发者大使，获得技术培训、行业资讯和社区参与机会。整体来看，本节课强调的是：学习完成后不要停在教程里，而要通过项目、黑客松、社区和行业活动，把知识转化为真实经历与职业机会。
