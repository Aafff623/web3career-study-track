# daily-log 规范

每天一个文件夹，命名 `YYYY-MM-DD/`，内含：

| 文件 | 用途 |
|------|------|
| `__index__.md` | 当日索引：概览、参考链接、资料汇总 |
| `YYYY-MM-DD.md` | 当日学习笔记（课程内容、Co-Learning 讨论、问答记录） |
| `TASK.md` | 当日任务与产出（打卡内容、交付证明、Tx Hash） |
| `assets/` | 截图、图片等静态资源 |

## __index__.md 模板

```markdown
# YYYY-MM-DD

## 今日概览

- 课程/活动：
- 状态：

## 参考链接

-

## 备注

```

## YYYY-MM-DD.md 模板

```markdown
# YYYY-MM-DD 学习记录

## 课程/活动内容


## 关键收获


## 问题与讨论

```

## TASK.md 模板

```markdown
# YYYY-MM-DD 任务

## 任务描述


## 产出


## 交付证明（链接/截图/Tx Hash）

```
