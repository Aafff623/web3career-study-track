# AI × Web3 School 2026 开营仪式

![](https://i0.hdslb.com/bfs/archive/0ae2b58418782a2f0e7ee857c6b264d8f1542698.jpg)

## 活动摘要

- 这是 "AI × Web3 School" 第一期开营仪式，由 ZAI 领衔赞助。活动完全免费，为期三周，前两周为 Bootcamp 高密度打卡学习，第三周衔接黑客松 Workup 并最终路演。
- 本期要点：
  - 主办方联合多位资深开发者，构建了**分级的 AI 和 Web3 知识图谱与手册**，并引入了基于 **Hermes Agent 的学习助手**，辅助学员配置环境、安排计划与记录笔记。
  - 赞助商 ZAI 分享了其开源大模型 **GLM 5.1** 在编码、Agent 任务上的领先表现，尤其在长时间自主构建复杂工程（如 8 小时生成 Linux 桌面）展现出极强韧性。
  - 多位助教及老学员分享了从"碎片化信息"走向"系统性理解"的共学经验，强调 Web3 的去中心化特性正为 AI 提供"不可篡改的宿主环境"，并倡导带着问题与好奇心进入交叉领域。
- 整个活动不仅是知识讲授，更是在构建一个透明、互助的 Builder 协作网络。

## 元数据与结构分析

- **时间与组织**：完全免费，无隐形收费。每周一三五晚间有助教答疑（Co-Learning），工作日有专题分享，周末可休息两天但需坚持打卡。
- **积分机制**：通用、AI、Web3 及综合赛道，按周和总榜排名，优胜者拥有隐藏福利。未连续打卡将被淘汰出积分系统。

> *这种"倒逼输出"的机制，本质上是在筛选出真正能动手的 Builder，而不仅仅是听众。想躺平听完的，在这里可能"活"不过第一周。*

## 核心议程与洞见

### 1. 为什么有 AI × Web3？

海老师（协议研究员、以太坊开发者）给出了一个很"硬核"的类比：

- **碳基生命的要素**：地球、物理定律、DNA、能量代谢、生死选择。
- **AI 硅基生命的要素**：共识规则、不可篡改、价值流、Gas 费、多 Agent 协作与淘汰（智能合约执行）。

> *他认为，如果宿主环境（如中心化服务器）是可控的，AI 就是一个奴隶；只有跑在去中心化、不可篡改的链上，智能体才能获得真正的"独立意识"。这不仅是写代码，是在为数字生命构建"地球"。*


### 2. ZAI 模型的能力揭示

Kara 分享了 ZAI 的 **GLM（General Language Model）** 系列。特别是 **GLM 5.1**，这是一个能在无人干涉下，仅凭一句指令迭代数百个回合、构建拥有 50+ 个全功能应用的 Linux Desktop 的模型。

- **关键能力**：全自主的任务分解、计划排布、代码编写与 Debug。
- **Taste Arena / Code Arena 表现**：基于人类盲测偏好，在编码领域持续霸榜。

> *这里有一个反常识的点：大部分人觉得 AI 是"辅助写代码"，而 ZAI 展示的是"AI 作为全栈架构师"长时间独立作业。这对于 Web3 自动化脚本、智能合约审计 Agent 的开发是极大的效率提升。*


### 3. 学习方法论：从碎片到大图景

老学员小白的分享切中了很多新人的痛点：

- **痛点**：看推特、刷 B 站觉得什么都懂，但全是碎片。
- **解法**：本次共学营提供的不仅是课程，更是一个 **HandBook 知识路线图**。涵盖大模型底层（LLM）、链上支付、隐私、可组合性等逻辑树。
- **核心原则**："开始一件事只需要情绪，完成一件事需要收官的定力"。

> *如果你只是被"AI+Web3= 暴富"吸引来，你很可能会失望；但如果你是带着"构建数字世界的底层逻辑"而来，这里的手册和助教能帮你节省至少 3 个月的无序试错时间。*

## 核心工具与配置

### 1. 学习助手：Agent 配置指南

Dragon 老师演示了如何在 TG 中配置个性化的学习管家：

1. **平台密钥**：进入 Profile 生成专属 `Agent Security API Key`。
2. **环境变量**：严禁将 API Key 明文丢进聊天框，应在机器本地配置。
3. **自动化同步**：连接 GitHub 仓库同步学习笔记，连接 Web3Career 平台读取课程表。
4. **场景应用**：只需发送"今天想学最小的方案"，Agent 会自动编排任务、提醒打卡，甚至陪你进行黑客松的"头脑风暴"。

> *这个 Agent 不是你给他打工，是它给你打工。能够用好 Agent 来管理自己的学习流，本身就体现了"AI+Web3"的组合思维。*


### 2. 资源与路线图

- **AI 技能图谱**：从大模型微调到 Agent Workflow。
- **Web3 脚手架**：钱包创建、EVM 兼容链操作、链上签名执行。
- **交叉领域**：Agent Commerce（自动交易/店铺管理）、Dev Tooling、Governance。
