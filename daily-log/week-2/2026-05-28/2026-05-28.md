### 3. Hackathon 方向终于定了——Smart Account + Session Key

这是今天最有收获的一部分。

之前在四个候选方向里纠结了很久：
- #1 Smart Account + Session Key
- #2 Agentic Commerce 闭环
- #3 AI-native Wallet
- #4 On-chain Data Analysis Agent

今天系统梳理后，确定选 **#1 Smart Account + Session Key**。

**一句话定位**：
> 给 AI Agent 一把"只能在某段时间、某个金额内、做某类事"的钥匙——用户随时可查看、可撤销。

**选定理由**（快速版）：
- 生态最成熟：ERC-4337 主网 + ZeroDev/Biconomy SDK 可用
- 与预习笔记衔接最紧：Agent-Wallet / Account-Abstraction / Machine-Payment 都直接相关
- 4 周能做完完整 Demo：创建 SA → 签发 Session Key → Agent 执行 → 用户撤销
- 排除 #2 是因为状态机太复杂做不完，#3 偏前端不是技术长板，#4 可行但叙事张力不如 #1

**核心闭环**：
```
用户创建 Smart Account
    ↓
用户给 Agent 签发 Session Key（金额上限 / 有效期 / 操作白名单）
    ↓
Agent 在限制内自主执行链上操作
    ↓
用户随时查看 Audit Trail 并撤销 Session Key
```

Cobo 的直播对这次方向确定帮助很大——它分享的 MPC + Pact + Recipe 三层架构，和我设计的 Session Key 策略在架构上是高度同构的。特别是 Pact 的 Intent/Policy/Completion Condition 这四个要素，直接可以作为 Session Key 策略设计的参考框架。
