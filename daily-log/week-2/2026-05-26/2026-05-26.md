## 晚间活动笔记

### Virtuals（19:00-20:00）

Virtuals Protocol 的核心逻辑是**把 AI Agent 资产化**——用户创建 Agent、持有其代币、分享其收益。对 Hackathon 的启发：

1. **Agent 经济模型** —— 如果 Smart Account 让 Agent 能执行交易，那 Agent 本身如何被拥有和定价？Virtuals 的代币化思路可以作为扩展设计
2. **去中心化所有权 vs 托管安全** —— Virtuals 把 Agent 所有权交给社区，但 Agent 的私钥/操作权限如何安全托管？这正是 Smart Account + Session Key 要解决的问题
3. **收益分配的链上自动化** —— Agent 产生的收益按持币比例自动分配，Smart Account 的 programmable 特性天然适合这种场景

### Cobo Agentic Wallet（20:00-21:00）

Cobo PM 分享的核心问题是**"Agent 凭什么相信钱包会按它的意图执行"**——这跟人类用户担心钱包安全是同一个问题的延伸：

1. **Agent 钱包的特殊需求** —— Agent 7×24 运行、高频交互、无法像人类一样手动确认每笔交易，需要预设策略和自动审批流
2. **Smart Account 的契合点** —— ERC-4337 的 bundler + paymaster 模式天然适合 Agent：批量执行、代付 gas、用户操作抽象化。Cobo 的思路验证了 Session Key 在机构级场景的必要性
3. **策略引擎 + 权限粒度** —— Cobo 提到"不是给 Agent 无限权限，而是给它特定条件下的有限权限"——这正是 Session Key 的设计哲学（时间限制、金额限制、操作类型限制）
4. **MPC vs Account Abstraction** —— Cobo 作为 MPC 基础设施提供商，也在探索 AA 的结合点。对 Hackathon 的启示：Session Key 可以作为 MPC 和 AA 之间的桥梁，MPC 管密钥分片，AA 管权限策略
