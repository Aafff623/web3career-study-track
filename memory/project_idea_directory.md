2026-05-18 创建 `idea/` 目录，定位为"想法的草稿本"。

目录结构：
- `idea/skills/` — 可复用的 skill 原型（如 pre-study-note、daily-log-sync）
- `idea/workflows/` — 可固化的 workflow 模式

**Why:** 在整理 11 节笔记的过程中发现很多重复模式可以抽象成 skill/slash command，需要一个地方先记录再验证。

**How to apply:** 日常 workflow 中发现重复模式就记到 idea/，定期回顾哪些值得做成正式 skill。
